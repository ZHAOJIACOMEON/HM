## 一、整体设定

- 主题：夜晚星湖 + 从天空垂下的礼物盒，抽取「今日份小礼物 / 餐食」的治愈系盲盒页面
- 视觉基调：**手绘白色线稿风**（roughen 抖动滤镜 + 铅笔描边 + 柔和曲线，忌横平竖直、忌直线堆砌）
- 双主题：白天 / 夜晚（原左上角折角开关切换，后暂时隐藏）
- 双盒语义：左盒暖金色 = 好心情，右盒青色 = 坏心情
- 数据链路：星星列表 / 餐食数据全部来自后端接口，前端不内置假数据

## 二、迭代时间线（用户原始需求汇总）

### 第 1 轮 · 礼物盒场景诞生
- 删除页面蒲公英部分（茎 / 叶 / 冠毛 / 光晕）
- 改为参考图构图：**礼物盒从天而降、垂下来**
- 白色的线，礼物盒白色线稿
- 礼物盒垂下来的顶端绳子**类似将天空撕开一个三角，需要折角效果**
- 礼物盒微微发光、吸引视觉焦点，可增加动画元素

### 第 2 轮 · 撕口与绳子形态
- 撕口改**平滑曲线**，不要锯齿状三角裂口
- 撕口里面需要**亮一些**（即将升起的太阳的光透出来）
- 绳子加长：垂到水面 100px 左右的位置
- 发光方式替换：模糊白色副本呼吸发光**有重影不美观**，需换掉
- **点击哪个盒子，哪个盒子晃动**
- 两只盒子做**颜色区分**，代表好心情和坏心情

### 第 3 轮 · 尺度调整
- 撕口直径改大
- 礼物盒放大 1 倍
- 绳子改细

### 第 4 轮 · 光效克制
- 删除撕口两端卷边线外的**半透明半圆弧**（椭圆光晕）
- 删除撕口分叉处的**小白点**（亮核）
- 撕口内黄色**降低透明度**，不要太明显
- 盒子要吸引视觉：增加**呼吸效果**，切勿重影

### 第 5 轮 · 奖品卡片位置
- 点击盒子后的奖品卡片被遮挡，需出现在**屏幕水平垂直居中**位置

### 第 6 轮 · 便签化

### 第 7 轮 · 便签排版设计

- 纸上文字采用**手写字体**，设计排版
- 增加**心情文案**（如「允许心情偶尔的乌云」等），多展示内容、美观为主

### 第 8 轮 · 排版权重
- 排版不美观、内容无权重关系
- 卡片不要太横平竖直，**与整体线稿风格相符**

### 第 9 轮 · 星空页星星样式
- 右上角星星打开的数据页：星星改为**闪闪发光的实心星星**，且**变小**

### 第 10 轮 · 星星极致缩小 + 增加餐食入口

### 第 11 轮 · 对齐后端的录入表单

## 四、接口对照（均已验证）

| 前端调用 | 后端路由 | 用途 |
|---|---|---|
| GET `/query_all_food` | ✓ | 星空列表 / 打开星空页刷新 |
| POST `/add_food` | ✓ | 录入餐食 / 撤销恢复 |
| PUT `/update_food/{id}` | ✓ | 编辑卡片保存（全量四字段） |
| DELETE `/delete_food/{id}` | ✓ | 删除星星 |
| GET `/recommend_food?mood=good` | ✓ | 心情推荐（查询用） |

- 后端运行：`uvicorn main:app --port 8001`（8000 被其他项目占用）
- 前端环境变量：`.env.local` → `VITE_API_BASE=http://localhost:8001`
- 注意：后端进程关闭后需手动重启，否则前端静默进离线兜底

## 五、踩坑与修复记录（技术备忘）

1. **CSS transform 覆盖 SVG 定位属性**：sparkle / 缩放动画需嵌套包装 group，不能直接写在带 transform 属性的元素上
2. **发光勿用模糊副本**：会产生重影，统一用 `drop-shadow` 呼吸动画
3. **transform 祖先影响 fixed 定位**：奖品卡片曾被带 transform 的容器限制，改为 Fragment 移出容器 + fixed 居中
4. **loading 未复位**：fetchMeal 缺 `setMealLoading(false)`（early-return 跳过），按钮永禁用；统一 try/catch/finally
5. **setPointerCapture 吞 click**：拖拽捕获元素后 click 被重定向，子元素 stopPropagation 收不到；点按判定统一放 hook 里（lastMoved 区分拖拽）
6. **useCallback stale closure**：再抽一次经 drawRef 延迟取最新 handleDraw，避免旧 phase 拦截
7. **预填数据语义**：录入入口的预填 = 库外候选池；展示数据 = 数据库。两条线不可混
